# Rhyan Aditia — Portfolio

Portfolio website for GitHub Pages.

## Publish
This repository should be named `rhyanaditia.github.io`. Keep `index.html`, `style.css`, and `contact.vcf` in the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

Website URL: https://rhyanaditia.github.io

## Before sharing publicly
- Replace the WhatsApp placeholder link (`https://wa.me/`) in `index.html` with your WhatsApp number in international format without `+` or spaces.
- Replace the LinkedIn homepage link with your personal profile URL.
- Verify employer names, dates, and work duties in the Experience section.
- Add a CV PDF to the repository and link it from the page if desired.
- The language skill bars are visual estimates; adjust them to your actual proficiency.
